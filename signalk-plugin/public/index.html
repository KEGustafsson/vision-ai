Choose your hardware

Signal K runs in a container here, so this page can't tell what the board is. The vision container answers on 127.0.0.1:7000 of the computer it runs on: give the Signal K container host networking, or set Vision container base URL in the plugin settings to an address it can reach.
Not sure which one you have?
Run this on the computer that will run the container:
uname -m; head -1 /etc/nv_tegra_release 2>/dev/null || echo "not a Jetson"
aarch64 + # R36 …Jetson Orin, JetPack 6 → Jetson Orin · DeepStream
aarch64 + # R35 …Jetson Xavier, JetPack 5 → Jetson Xavier · DeepStream
not a JetsonA PC, mini-PC or Raspberry Pi → CPU only
Signal K runs on a different computer?
The container answers only on 127.0.0.1:7000 of the computer it runs on. Don't open port 7000 to the boat's network: anyone on it could watch the cameras. Run this on the Signal K computer instead, and leave Vision container base URL at http://localhost:7000. Keep the tunnel running with autossh or a systemd service.
ssh -N -L 7000:127.0.0.1:7000 user@vision-computer
